# Gravity: One-Star Review

A deadpan one-star review of gravity, an everyday essential everyone relies on — written in one line, 156 characters.

> I have trusted gravity with my phone, keys and coffee all my life, and it has never once caught a single thing. Its customer service line is just the floor.

`main.ts` (Node 22, no network, no file reads) writes the review to `/output/entry.txt`, deterministically.
